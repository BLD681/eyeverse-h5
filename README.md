# EYEVERSE｜眼界宇宙

React + Vite + TypeScript 首页交互原型。

## 运行

```sh
pnpm install
pnpm dev
```

打开开发服务器显示的本地地址。同一局域网的手机可访问服务器显示的 Network 地址（需系统防火墙允许）。

```sh
pnpm build
pnpm exec playwright test
```

浏览器检查默认使用本机 Microsoft Edge，可在 playwright.config.ts 调整。

## 视觉资产

`public/assets/home/home_hero_master.png` 是用户母图的原样副本，未重新生成、压缩或修改。资源配置位于 `src/config/visuals.ts`。图片按 9:16 等比完整展示，长屏上下由深蓝黑底色承接；桌面与横屏保持居中的竖幅体验。

文字、按钮均为 HTML/CSS。呼吸光效是独立 CSS 叠层，可通过 `.optical-breath` 调整或关闭，不改变原文件。转场中心为图片的 50% / 46%。

## 动画与范围

图片加载及解码完成后：0–1 秒深蓝环境光苏醒，1–3 秒主视觉渐显，3–4 秒透明光学结构完成一次闭合与展开，4–5 秒虹膜聚焦并显示品牌与入口。5 秒后进入低密度 Canvas 粒子、呼吸光和缓慢光环组成的等待状态。

点击按钮以 2.2 秒完成瞳孔增亮、景深推进、暗角收束、模糊与淡出，进入 `#portal`。每次重新打开或刷新 H5 都会播放开场，从 Portal 返回时直接进入等待状态。支持系统减少动态效果、键盘操作及浏览器返回。

四个专题页面本体尚未开发；Portal 已保留选择状态和后续路由接入位置。项目没有使用带字参考图或生成新的视觉资产。

## Vision Portal

`public/assets/portal/portal_core_master.png` 是无字主视觉的原样副本。带字布局参考图没有进入项目，也不会在页面中加载。

Portal 以中央 Vision Core 为视觉锚点，四个主题按钮覆盖在主图对应球体上。所有英文与中文名称均为 HTML 文字。页面进入时先显现中央核心，再逐步展开四个主题节点；选择节点后会放大并高亮当前入口、遮暗其余入口，同时保留未来接入专题路由所需的选择状态。

## Dry Eye｜眼中的湖

`public/assets/dryeye/dryeye_base.png` 是无字母图的原样副本。干涩与恢复参考图没有进入项目。

专题包含引导、泪膜状态旅程和科普收束三个页面状态。交互页始终显示同一张母图，通过 0–100 的 `drynessLevel` 控制水面宽高、湖缘暴露、灰褐色迁移、轻微干燥纹理、边缘收束、亮度、饱和度和高光。进入恢复方向后，水位、蓝色与波纹按连续参数逐步回来。支持纵向指针滑动、鼠标滚轮、键盘方向键与右侧状态节点。

向上滑动让水分从健康、疲劳推进至干涩峰值；到达峰值后，反向向下滑动进入恢复。恢复完成后继续下滑或点击“了解泪膜健康”，进入 HTML/CSS 科普收束页。
